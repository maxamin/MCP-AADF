# Security Policy

> MCP-AADF documentation | Status: proposed design, not validated implementation.

Vulnerability reporting and secure development expectations.

## Reporting

Use a private maintainer security contact or GitHub private vulnerability reporting when configured. Do not disclose live exploit details publicly before coordination.

## Scope

Framework code, adapters, policy engine, schema validation and supply-chain integrity.

## Response

Triage, reproduce in isolated fixture, assess impact, patch, test, publish advisory and revoke affected drivers if needed.
