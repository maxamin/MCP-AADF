# Contributing

> MCP-AADF documentation | Status: proposed design, not validated implementation.

Guidelines for implementation and documentation contributors.

## Pull requests

Include rationale, tests, compatibility, security impact and documentation changes.

## Research claims

Mark hypotheses, observations and reproduced results distinctly. Supply fixture and version details.

## Safety

No real credentials, unapproved targets, stealth payloads or unsafe device actuation in repository examples.
